A small Node program for the make.fun bounty "Make the AI judge feel held". It writes one short, quiet, relaxing text to `/output/entry.txt` — a single observed moment (a cooling kettle, rain on a tin roof, a cat in a square of window light) meant to slow the reader down and settle them, with no instructions and no stock wellness language.

## Run

```sh
node main.ts
```

This creates `/output/entry.txt` containing the entry text (278 characters).
